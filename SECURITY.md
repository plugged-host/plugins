# Security

Please report vulnerabilities privately, not in a public issue: open the affected repository on
GitHub and use **Security › Report a vulnerability** (GitHub private vulnerability reporting). If
you are not sure which repository it belongs to, use this one.

Include what is affected, how to reproduce it, and what an attacker could do with it. We answer in
the report thread and credit you in the fix unless you prefer otherwise.

This covers the code in the plugged-host and switched-cloud organisations. noprofit.space accounts
is closed source; issues with it can be reported here too and are forwarded.
